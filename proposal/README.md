# Project Proposal Assembly Checklist

## Task 1 Reviewer

- [ ] Independent one-page review completed before opening the instructor AI review
- [ ] Problem and motivation explained
- [ ] Proposed method summarized
- [ ] Dataset and experimental setup identified
- [ ] Exact principal results checked against the paper
- [ ] Contributions and limitations stated
- [ ] At least three instructor-AI claims assessed as right, shallow, wrong, or fabricated
- [ ] Every disagreement row includes evidence from the paper

## Task 2 Student Researcher

- [ ] Specific two-month topic stated
- [ ] Reason for choosing the topic explained
- [ ] Connection to course topics explained
- [ ] Application areas identified
- [ ] Three AI-generated follow-up ideas recorded
- [ ] Each AI idea labeled feasible, already published, or technically flawed
- [ ] Each label has a one-sentence justification
- [ ] Origin of the selected topic identified as team or AI

## Task 3 Reproducibility Checker

- [ ] New idea and implementation approach described
- [ ] Baseline, dataset, metrics, and robustness variables identified
- [ ] Demonstration output described
- [ ] AI coding assistant named
- [ ] Verification process explained

## Submission checks

- [ ] Team and paper information complete
- [ ] All relied-upon AI outputs recorded in `AI_AUDIT.md`
- [ ] Course identifier confirmed
- [ ] Placeholders and template instructions removed from the final proposal
- [ ] Page limit confirmed
- [ ] Final PDF visually checked
